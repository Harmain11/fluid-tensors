Prompt-Conditioned Functional Effects in a Transformer

TL;DR

The original 32-question study showed that the same frozen edit measured +0.206 under original wording but −0.021 after rewording. Version 3 adds a fresh GPU run on 64 further question identities: the signed matched contrast averaged +0.193491 (95% question-bootstrap interval [+0.166896, +0.219002]), with 62 of 64 paired effects positive.

The original and confirmation results describe output-logit response geometry in one pinned model/edit setting—not improved math-answer accuracy, independent model-family replication, proof of a particular circuit, or general-purpose model repair.

When a model's behavior changes after a weight edit, it is tempting to attribute the change entirely to the intervention. But prompts are part of the computation too. A small change in wording can change which features the model activates and how an edit appears in a recorded response measure.

Our question is simple: does the same historical edit give the same measured response across different ways of asking a question? We analyze the archived numbers directly, keeping the claims within what the data can establish.

Version 3: we ran the model again on 64 more questions.

The first release audited 1,024 measurements already in an archive. The next step was a new GPU run on the same pinned Qwen2.5-1.5B-Instruct model and the same frozen rank-four edit. We replayed the original 32-question contrast, then tested 64 additional GSM8K question identities outside the frozen historical registry. This is confirmation within one model, not a claim about every AI model.

After matching input token counts by a recorded newline-token procedure, the signed-edit contrast averaged +0.193491 (95% question-bootstrap interval [+0.166896, +0.219002]). The same-sized orthogonal control was +0.004060 (interval crosses zero). All 128 original replay measurements matched the archived results. These statistics describe how the model's output logits respond to the edit, not whether it answered the math questions correctly.

The 64 additions came from GSM8K's training split, so independence from model pretraining is unknown. No second model or separate laboratory was tested. Read the dated confirmation, PDF, complete GPU ZIP and audit trail →

How we checked the measurements

We reconstructed the factorial table from the archived CSV and verified that every question, direction, wording, and template combination was present exactly once. The principal contrast subtracts each generic-template response from the corresponding math-plus-format response, then averages over 32 question units.

The original numerical source is checksummed and the plots are reproducible without downloading model weights. This was the original source-level reanalysis. A distinct November 18 GPU confirmation is now available in the section above, with its own archived checks and limitations.

What this result does not establish

  • Not answer accuracy. Attenuation is a functional-response measure, not a correctness score on math tasks.
  • Residual format confounds. The original archive was not length-matched. The later 64-question GPU confirmation equalized input token counts through explicit newline-token insertion, which does not eliminate all format, tokenization or position effects.
  • Not cross-model or external-lab replication. The November 18 run replayed the original contrast and measured 64 additional questions on the same pinned model/edit and L4 environment; independent model families were not evaluated.
  • Not a general repair mechanism. One historical model/edit setting and one rotated control are insufficient for a cross-model causal claim.

These limits do not make the archived observation uninteresting. They define the next, testable experiment: independently selected edits, matched prompts, stronger controls, and final-answer correctness evaluation.
