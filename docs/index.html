Research note / Transformer model editing

One Frozen Edit, Four Ways to Ask

Prompt-Conditioned Functional Effects in a Transformer

AuthorHarmain Dastgir
AffiliationIndependent Researcher
PublishedNovember 16, 2026
StatusWorking preprint
TL;DR

We revisited an archived experiment where a transformer weight edit was held fixed and the wording of a question changed. The measured functional attenuation contrast was +0.206 under the original wording but −0.021 when the question was reworded.

This is evidence of prompt-conditioned variation in one historical model/edit setting—not improved mathematical answer accuracy, proof of a particular neural circuit, or general-purpose model repair.

When a model's behavior changes after a weight edit, it is tempting to attribute the change entirely to the intervention. But prompts are part of the computation too. A small change in wording can change which features the model activates and how an edit appears in a recorded response measure.

Our question is simple: does the same historical edit give the same measured response across different ways of asking a question? We analyze the archived numbers directly, keeping the claims within what the data can establish.

The result

The archived dataset contains 1,024 measurements from 32 question units, two historical edit directions, four wording variants, and four instruction templates. The comparison below is the signed direction's average attenuation under math plus format minus attenuation under a generic instruction.

The question-paired original-minus-reworded difference averaged +0.226216, with a descriptive 95% question-bootstrap interval of [+0.184256, +0.274149] from 20,000 draws. All 32 paired comparisons were positive within this historical panel, with varied magnitudes.

How we checked the measurements

We reconstructed the factorial table from the archived CSV and verified that every question, direction, wording, and template combination was present exactly once. The principal contrast subtracts each generic-template response from the corresponding math-plus-format response, then averages over 32 question units.

The original numerical source is checksummed and the plots are reproducible without downloading model weights. This is source-level reanalysis, not independent execution of the historical weight-editing experiment.

What this result does not establish

  • Not answer accuracy. Attenuation is a functional-response measure, not a correctness score on math tasks.
  • Not a length-matched comparison. The instruction templates differ by 14–15 prompt tokens; token positions changed too.
  • Not an independent model-side replication. The source table was reanalyzed, but the original model inference and edit selection were not rerun.
  • Not a general repair mechanism. One historical model/edit setting and one rotated control are insufficient for a cross-model causal claim.

These limits do not make the archived observation uninteresting. They define the next, testable experiment: independently selected edits, matched prompts, stronger controls, and final-answer correctness evaluation.
