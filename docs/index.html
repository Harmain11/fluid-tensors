01 A question about weight editing

The edit stayed frozen.
The effect didn’t.

We changed how a question was asked—not the historical weight edit. The model’s measured response changed with it.

An open, question-level audit of prompt-conditioned functional effects in a transformer. A narrower but more revealing result than a blanket claim of “model repair.”

05 The honest boundary

A strong contrast.
Not a claim of repair.

A serious result also says what it cannot establish. This is where the next experiments begin.

Read the limitations ↗
01 /

Attenuation is not accuracy.

The reported values are functional response geometry, not the number of math answers corrected.

02 /

Prompt conditions were not length-matched.

The compared instruction templates added 14–15 tokens, changing positions alongside semantics.

03 /

One historical edit is not generalization.

No newly selected directions, multiple model families, or independent GPU reproduction are included here.

04 /

A rotated control is not a circuit proof.

One 90° direction comparison does not establish a unique causal mechanism.
